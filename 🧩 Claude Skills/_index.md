# Claude Skills Index

This vault is Claude's brain. All skills here are junctioned into `~/.claude/skills/` and load automatically.

**Edit any SKILL.md here in Obsidian and changes reflect in Claude instantly.**

## How it works
- Each subfolder is a skill category
- Each skill folder contains a `SKILL.md` (the skill definition) and `_notes.md` (your notes)
- Windows directory junctions link `~/.claude/skills/<name>` to these folders
- Invoke any skill by typing `/<skill-name>` in Claude Code

## Categories
- **Coding & Dev** - 25 skills for coding, debugging, testing, dev workflows
- **Automation & Playwright** - 4 skills for browser automation and file management
- **Documents & Writing** - 16 skills for docs, PDFs, presentations, writing
- **Planning & Brainstorming** - 9 skills for planning, ideation, research
- **Discovery (Awesome Lists)** - Curated skill indexes and collections
