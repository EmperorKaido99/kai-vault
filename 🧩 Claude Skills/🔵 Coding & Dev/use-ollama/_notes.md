# use-ollama

**Description:** Switch the session to route prompts through Ollama Cloud free-tier models.

**Source:** Custom skill (created by me)

**Date added:** 2026-09-05

## Why I picked this

When Claude Code tokens run low, I want a single command to flip the session over to Ollama without any manual key management. `/use-ollama` reads the key silently and starts proxying prompts immediately.
