# switch-model

**Description:** Fallback to Ollama cloud models when Claude tokens are running low or exhausted.

**Source:** Custom skill (created by me)

**Date added:** 2026-09-03

## Why I picked this.

When Claude Code token limits are hit mid-session, I need a quick way to continue work using Ollama cloud. This skill reads the API key from my local read-only file and gives me ready-to-run commands so I don't lose momentum.
