# Inbox

Everything new lands here first, unsorted. New notes are created here by default.

**Rule:** the Inbox is empty by the end of each week. Each note gets one of:
1. Move to [[02 Projects/README|Projects]] if it serves something with an end date
2. Move to [[03 Areas/README|Areas]] if it is an ongoing responsibility
3. Move to [[04 Resources/README|Resources]] if it is reference material
4. Delete it
